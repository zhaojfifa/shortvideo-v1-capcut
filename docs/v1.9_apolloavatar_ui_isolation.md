# v1.9 ApolloAvatar UI Isolation Rules (Non-Interference Contract)

## Goal
Introduce the ApolloAvatar scene in v1.9 without breaking or coupling the existing "Suitcase" baseline flow.
ApolloAvatar must have its own list page and its own "new task" page, isolated from the legacy /tasks/new flow.

## Hard Principles (Must Hold)
1) Non-interference:
   - Do NOT modify the existing Suitcase flow logic or UI behavior.
   - ApolloAvatar UI must not be mixed into /tasks/new (legacy).

2) Scene Isolation:
   - Each new scene gets its own:
     - Task list page
     - Task creation page
   - Shared components are allowed (topbar, lang tabs, CSS), but routing and task payloads must be scene-scoped.

3) Base Workflow as Foundation:
   - The legacy pipeline remains the base (translation / dubbing / packaging).
   - ApolloAvatar extends by creating a scene-scoped task that later triggers:
     - video generation → (optional) translate → dub → pack

4) Billing Safety Gate:
   - Default mode must be Demo (no external API call).
   - Live mode must require BOTH:
     - global env gate enabled
     - task-level live_enabled = true
   - UI must make the cost boundary explicit.

## Navigation Rules (v1.9)
Top scene tabs (center area) should be:
- Digital Human (ApolloAvatar)
- Hot-Follow (placeholder, empty for now)
- Tools

The "Hot-Follow" entry is a reserved scene slot. It should render a placeholder page (Coming soon) and must not call any external APIs.

## Routes (UI)
- Digital Human list:     /tasks?kind=apollo_avatar
- Digital Human new task: /tasks/apollo-avatar/new
- Hot-Follow placeholder: /tasks/hot-follow   (or equivalent)
- Tools:                  existing Tools Hub route (unchanged)

## ApolloAvatar List Page Rules
- The list page must only show tasks where kind == "apollo_avatar".
- It must not render Suitcase tasks in the Digital Human tab.
- "New Digital Human" button must navigate to /tasks/apollo-avatar/new.

## ApolloAvatar New Task Page Rules
Fields (CN default, bilingual supported):
- Duration: 15s / 30s (60s hidden)
- Live (billing): checkbox (default off)
- Seed: integer (optional; default empty)
- Character image: default demo asset path
- Reference video: default demo asset path
- Prompt: text

Actions:
- Create Task: creates task record only (no API call)
- Generate (Demo): produces demo output (no external API)
- Generate (Live): only enabled if billing gate is open

## Acceptance Checklist
- [ ] /tasks/new has no ApolloAvatar section (fully isolated)

- [ ] Top tabs show: Digital Human / Hot-Follow / Tools
- [ ] Hot-Follow opens a placeholder page with no API calls
- [ ] ApolloAvatar new page includes Seed and submits it
- [ ] No changes to Suitcase flow behaviors or payload schema
