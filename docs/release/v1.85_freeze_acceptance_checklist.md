# Apollo-veo v1.85 冻结验收清单（Freeze Gate / Final）

定位：v1.85 = 稳态基座（The Stabilizer）
目标：把 SOP 固化为协议与交付包，确保运营/剪辑协同“可复制、可追溯、可复跑”。

---

## 0. 硬边界（必须写死）
- v1.85 不引入 v1.9 的资产库/变体引擎/高级编排器（允许字段占位，但不作为验收）。
- 不以“自动剪辑工程导出”为验收门槛；只验收 Smart Pack 可交付、README 可执行。
- 不引入 GPU Worker / 复杂 DAG / 资产派生链（全部属于 v1.9+）。

---

## 1. 冻结对象（工厂通用语言）

### 1.1 Scenario Spec Schema v1.0（冻结）
必备字段（示例口径）：
- scenario_spec_version（semver）
- platform / language
- selling_points（list）
- forbidden_words / forbidden_visuals
- reference_links
- deliverable_requirements（时长/比例/字幕/配音/交付格式等）

验收：
- 运营可独立填写，生成任务不需要工程解释字段。
- 字段变更遵循 semver，并进入 release notes。

### 1.2 Scene MSC（Minimum Scene Cell）Schema v1.0（冻结）
最小字段（允许为空，但结构稳定）：
- id
- asset_hash（口径固定：计算对象/算法/何时生成）
- script / audio / visual / subs

验收：
- 任意任务可映射到 MSC（至少 1 个 scene），字段不漂移。
- asset_hash 口径写入文档，不“拍脑袋”。

### 1.3 Smart Pack Schema v1.0（冻结）
目录结构冻结（建议）：
- README.md
- manifest.json
- Assets/Video/
- Assets/Audio/
- Assets/Subs/ (origin.srt / mm.srt / mm.txt)
- CopyBundle/（可选）
- Refs/（可选）

校验冻结：
- manifest 严格校验可在本地/CI 执行通过（存在性/字段一致/路径一致）。

验收：
- ≥2 条样板任务 pack 解压结构一致；manifest 校验通过；README 可执行。

## 2. v1.85 主链路稳定（P0 必须稳定）

### 2.1 双入口等价
- parse（链接解析）
- local_upload（本地上传）——v1.85 重点

验收：
- 两入口进入同一状态机与同一交付协议（Smart Pack）。

### 2.2 local_upload 冻结清单（必须包含）

#### 输入约束（冻结）
- Route：POST /api/tasks/local_upload
- file: UploadFile 必填
- 扩展名白名单 + 大小限制（MAX_LOCAL_UPLOAD_MB）
- 表单参数（口径固定，可选）：category/language/account/platform/template/title/note/style_preset/subtitles_mode/dub_mode

#### 落盘与对象（冻结）
- raw 落盘路径规则固定：video_workspace/tasks/{task_id}/raw/...
- 创建 TaskRecord：task_id/source/raw_path(or key)/created_at/status 必含

#### 对象存储上传（冻结）
- raw 上传 key 稳定（示例：default/default/{task_id}/raw.mp4）
- subtitles/dub/pack 产物统一走 artifact_storage 上传
- 日志打印 Uploading ... -> bucket/key

#### 自动推进（v1.85 gate）
- local_upload 完成后触发 AUTO_START
- 自动推进顺序：subtitles → dub → pack
- 最终日志：AUTO_PIPELINE_DONE
- 失败定位到 step，可单步重跑恢复

验收：
- 不进入 /ui 手动点按钮，等待可见 pack ready（或状态到 pack done）。
- subtitles/dub/pack rerun 幂等，不污染产物与状态。

## 3. Tools Hub（v1.85 收口目标）

### 3.1 IA & 路由冻结
- Tools Hub 独立入口可达（管理页/导航）
- 不影响主链路稳定（parse/sub/dub/pack）
- 分类枚举集稳定（素材/字幕/配音/生成/剪辑/发布/分析…）
- 支持：搜索（name/tag/keyword）+ 分类过滤

### 3.2 ToolCard Schema（冻结）
最小字段：
- tool_id, name, category
- capability_tags
- input_types, output_types
- provider
- entry_url（或 deep link）
- status（active/beta/deprecated）
- last_verified_at
- notes（可选）

### 3.3 Tool 与任务关联（冻结）
- Task 可保存选用工具清单（用于协同记录）
- v1.85 不要求“工具执行”，只要求“可找、可选、可引用”

验收（运营视角）：
- 1 分钟内找到：配音/关键帧/视频生成/换脸/数字人/剪辑工具
- 卡片信息足够完成：选择 → 打开 → 开始用

---

## 4. Smart Pack + README（交付稳定）

README 必含：
- 导入剪辑软件步骤（CapCut/YouCut 至少一条可跑通）
- 分轨说明（Video/Audio/Subs）
- 任务信息（语言/平台/时长/节奏建议）
- 注意事项（禁词/硬字幕/画面风险提示）

验收：
- 剪辑师仅按 README 可完成导出成片（无需工程补充说明）。
- pack 下载链路稳定（链接/二维码/归档字段口径一致）。

---

## 5. 可重跑与可观测（最小门槛）

### 5.1 状态机可观测（冻结）
每 step 至少：
- status: pending/running/done/failed
- error（错误码/错误信息）
- duration_ms
- 产物列表（key/path）

### 5.2 节点级重跑（冻结）
- subtitles/dub/pack 单步重跑
- 幂等策略（覆盖/去重 key）口径明确并写入文档

---

## 6. Freeze 通过判定（Final Gate）
必须同时满足：
1) local_upload 自动推进稳定（AUTO_PIPELINE_DONE）  
2) Tools Hub 可用（分类/搜索/卡片 schema/任务保存选用工具）  
3) Smart Pack 稳定（结构一致、README 可执行、manifest 校验通过）  
4) 失败可定位可恢复（失败定位到 step；单步 rerun 可恢复）  
5) Tag & Release Note（稳定 tag + 冻结项变更说明）

---

## 7. Tag / 分支策略（基座记录）
- v1.85 稳态 tag（annotated）：apollo-veo-v1.85-ops-stable-YYYYMMDD
- main 对齐：release/v1.85 fast-forward 合并到 main
- v1.9 开工分支：release/v1.9（基于 main 的 v1.85 稳态基座）

---

## 8. v1.85 明确不做（防走偏）
- 资产库（Asset Library）与变体引擎（Seed/Variant/Derivation）
- 长视频切片入库与自动合成链
- 自动剪辑工程导出作为硬验收
- GPU Worker / 复杂 DAG 编排框架引入
- 多账号规模化（v1.9/2.0 承接）
