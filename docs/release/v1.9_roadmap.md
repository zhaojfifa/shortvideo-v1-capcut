# Apollo-veo v1.9 路线图（基于 v1.85 稳态基座）

定位：v1.9 = “场景编排 + 资产沉淀”的第一版
目标：在不破坏 v1.85 稳态的前提下，把“工具驱动”升级为“场景驱动”，并让产物可沉淀复用。

---

## 0. v1.9 设计原则（必须遵守）
- 不破坏 v1.85：主链路（parse/local_upload → subtitles → dub → pack）继续稳态。
- 扩展必须“旁路化”：新能力以新增路由/新增字段/新增目录为主；旧协议不改语义。
- 运营优先：先做“可运营的场景包/工具编排入口”，再做“更智能的自动化”。

---

## 1. v1.9 的交付范围（Definition of Done）

### 1.1 Scene / Scene Pack（从“结构存在”到“可被用”）
- Scene Pack 成为任务交付的增强层：在 Smart Pack 基础上，增加可复用的“场景资产描述与清单”。
- 关键：**Scene MSC v1.0 不变**，在此之上新增 Pack 级结构（v1.9）。

交付物：
- `scene_packs/{pack_id}/manifest.json`（pack 级清单）
- `scenes/{scene_id}/scene.json`（scene 级清单，可引用任务产物 key）
- 任务到 scene 的映射（至少 1 scene，后续可多 scene）

验收：
- 运营可以选择一个 Scene Pack 作为“生产模板”，创建任务后产物仍按 v1.85 交付，但额外生成 Scene Pack 清单。

---

### 1.2 Tools Hub → 场景编排入口（从“可选”到“可编排”）
- v1.85：Tool 只是“可选可引用”
- v1.9：Tool 进入“编排清单”并可输出“执行计划”（Plan），但不强制所有工具自动执行

交付物：
- `ToolCard` schema 扩展字段（不破坏 v1.85 最小字段）：
  - `execution_mode`: manual | semi | auto
  - `plan_hooks`: 可挂载到哪个 step（subtitles/dub/pack/post）
  - `required_inputs`: 来自哪些产物 key
- `TaskPlan`（任务编排计划）：
  - `selected_tools[]`
  - `tool_chain[]`（有序）
  - `handoff_notes`（运营→剪辑）

验收：
- 任务详情页可以展示“计划”（plan）与“已选工具”，并可导出/复制给运营协作。

---

### 1.3 Asset Library（轻量资产沉淀：先可用，再完美）
目标：把“可复用的产物”沉淀为资产（字幕、配音、封面、B-roll 等），为 2.0 扩展做地基。

交付物（v1.9 最小版本）：
- Asset 记录：`asset_id/type/source_task_id/key/hash/meta`
- 可入库资产类型（先 3 类）：
  - subs（origin.srt/mm.srt/mm.txt）
  - audio（audio_mm.mp3/wav）
  - cover（如有）
- 资产检索（按 task / language / type / 时间）

验收：
- 选中一个历史任务的字幕/配音可复用到新任务（至少支持“复制引用”，不要求自动重混）。

---

### 1.4 交付包增强（Smart Pack v1.0 不破坏，新增 v1.9 增强层）
- 增强 CopyBundle：话题标签/评论引导/挂链链接/发布标题来源规则固化（配置化）
- 增加 Pack 内“交接卡”：
  - “本任务选用工具清单”
  - “场景说明”
  - “发布参数（可选）”

验收：
- v1.85 的 pack 校验依旧通过；v1.9 只是在 pack 内增加新文件与清单，不改变旧文件语义。

---

## 2. v1.9 工程里程碑（建议拆成 3 个 PR 波次）

### PR-1（P0）：Scene/Scene Pack 结构落地（不动主链路）
- 新增目录/清单生成器
- 任务→scene 映射
- 最小 UI 展示（任务页显示 scene pack 信息）

### PR-2（P0）：TaskPlan（编排计划）+ Tools Hub 扩展字段
- ToolCard schema 扩展（向后兼容）
- 任务保存 plan + 展示 plan
- 导出/复制交接信息（给运营/剪辑）

### PR-3（P1）：Asset Library 最小可用
- 资产入库：subs/audio/cover
- 资产检索与复用（复制引用）
- 观测指标：复用率/节省时间（简单埋点或日志）

---

## 3. v1.9 的验收清单（Gate）
必须满足：
1) v1.85 主链路完全不回退（同样的任务同样可跑通）  
2) Scene Pack 清单生成稳定（至少 2 条样板任务）  
3) TaskPlan 可保存/可展示/可导出  
4) 资产入库与复用可演示（至少 subs/audio）  
5) 新增字段/路由均“向后兼容”，不破坏旧 UI/旧 API

---

## 4. v1.9 不做（防扩散）
- 自动调用外部剪辑软件生成工程文件作为硬验收
- 多语言大规模扩展（只保留配置机制与占位）
- GPU/复杂 DAG 编排器
- 自动生成大量 B-roll（先支持引用与轻量入库）
