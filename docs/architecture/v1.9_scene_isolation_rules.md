# v1.9 Scene Isolation Rules (ApolloAvatar baseline)

## Non-interference
- Suitcase pipeline routes/pages MUST remain unchanged.
- New scenes MUST NOT be merged into `/tasks/new`.
- Each scene has its own:
  - list: `/tasks?kind=<scene>`
  - create: `/tasks/<scene>/new`

## Billing safety gate (double gate)
- Global gate (env): `ENABLE_APOLLO_AVATAR=1` and `APOLLO_AVATAR_LIVE_ENABLED=1`
- Per-task gate (meta): `live_enabled=true`
- Live execution requires BOTH true.

## Demo assets
- Large mp4 files MUST NOT be served from Render static.
- Use Cloudflare R2/CDN and `DEMO_ASSET_BASE_URL`.
- Small jpg/png can remain in repo for UX placeholders.

## i18n / encoding
- All templates and i18n bundles MUST be UTF-8 (no BOM).
- Add a CI/preflight utf-8 check to prevent regression.
